# Speedskating Manager Prototype

Dit is een eerste speelbare prototype van een schaatsmanagementspel:

- **Managementlaag**: beheer budget, trainingsfocus en selectie.
- **Race-laag (3D)**: bekijk een korte gesimuleerde race op een ovale baan.
- **Wedstrijdresultaat**: prestaties hangen af van stamina, techniek, sprint en moreel.

## Snel starten

```bash
python3 -m http.server 4173
```

Open daarna `http://localhost:4173`.

## Gameplay in het kort

1. Kies je trainingsfocus.
2. Koop eventueel betere faciliteiten (kost budget, verhoogt teamniveau).
3. Selecteer drie schaatsers.
4. Start de race en volg de live-ranglijst.
5. Ontvang prijzengeld en pas je strategie aan voor de volgende race.

## Volgende stappen richting volledige game

- Meerdere seizoenen met kalender, sponsors en contracten.
- Dieper AI-gedrag (bochtentechniek, slipstream, teamorders).
- Uitgebreidere 3D presentatie (publiek, animaties, camera-regie).
- Multiplayer/asynchrone rankings.
